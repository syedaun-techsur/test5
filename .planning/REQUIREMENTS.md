# Requirements: Simple To-Do App

**Defined:** 2026-05-07
**Core Value:** Users can quickly add and check off tasks without friction.

## v1 Requirements

### Task Management

- [ ] **TASK-01**: User can add a new task by typing text and submitting
- [ ] **TASK-02**: User can view their full list of tasks with completion status visible
- [ ] **TASK-03**: User can mark a task as complete (toggle between complete and incomplete)
- [ ] **TASK-04**: User can delete a task permanently from the list

## v2 Requirements

### Task Management

- **TASK-05**: User can edit the text of an existing task
- **TASK-06**: User can filter tasks by status (active / completed)
- **TASK-07**: User can reorder tasks via drag-and-drop

### Enhancements

- **ENH-01**: User can add due dates to tasks
- **ENH-02**: User receives reminders for due tasks
- **ENH-03**: User can organize tasks with tags or categories

## Out of Scope

| Feature | Reason |
|---------|--------|
| User authentication / accounts | Keeping it simple — no login needed for v1 |
| Collaboration / sharing | Single-user focus for v1 |
| Due dates / reminders | Complexity not needed for a very simple app |
| Tags / categories / priorities | Out of scope for v1 simplicity |
| Backend / API | localStorage-only for v1 — no server needed |
| Mobile app | Web-first; mobile is a future consideration |
| Real-time sync | No backend in v1 |
