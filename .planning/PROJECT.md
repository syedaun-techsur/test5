# Simple To-Do App

## What This Is

A very simple to-do app that lets users create, view, and manage a list of tasks. It is focused on ease of use with no unnecessary complexity — just the core task tracking a person needs day-to-day.

## Core Value

Users can quickly add and check off tasks without friction.
